## Overview

The goal of `shinypkg` is to showcase a modern, production-grade, testable, observable, robust, and performant R shiny app bundled as an R package with an emphasis on configurability, developer ergonomics, and composability.

## Installation

You can install the development version of shinypkg like so:

``` r
pak::pak("jimbrig/shinypkg")
```
